# Gestão Profissional na Prática — Landing Page

Site estático (HTML/CSS/JS), pronto para deploy direto no Netlify — sem build, sem framework.

Gerado a partir do projeto fonte (vinext/React) via `output: "export"`. Para atualizar este site após alterações no projeto fonte:

1. No projeto fonte, rode `npm run build`.
2. Copie o conteúdo de `dist/client` para esta pasta (substituindo os arquivos).
3. Commit e push.
